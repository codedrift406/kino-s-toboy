# Пойдём в кино? 💗

Романтичное приглашение на свидание в кино: розово-белая открытка, объёмный котик с цветами и попкорном, интро с единорогом и переходом через сердечко.

Сайт для Ақерке: [codedrift406.github.io/kino-s-toboy](https://codedrift406.github.io/kino-s-toboy/).

- Адаптировано для смартфонов; кнопки работают касанием.
- «Да» открывает билет на свидание и запускает сердечки.
- «Нет» убегает от мышки и касания, оставаясь в пределах экрана.
- Интро можно пропустить; учтена настройка уменьшения анимации.

## Локальный просмотр

В папке проекта запустите:

```sh
python -m http.server 4173
```

Откройте `http://localhost:4173/`.

## GitHub Pages

Опубликуйте файлы в репозитории. В **Settings → Pages** выберите **Deploy from a branch**, ветку **main**, каталог **/(root)**. Сборка не требуется.

Все пути к изображениям и скриптам относительные, поэтому сайт работает по адресу проекта `https://USERNAME.github.io/REPOSITORY/`.

## Уведомления

Нажатие «Да» автоматически передаёт ответ автору приглашения через Telegram-бота. GitHub Pages обслуживает статическую открытку, а отдельный серверный обработчик в [`backend/`](backend/README.md) отправляет сообщение. Подтверждение отправки появляется после успешного ответа сервера; при сбое можно повторить попытку.

В `notification-config.js` указывается только публичный HTTPS-адрес обработчика с путём `/api/reply`. Токен бота и ID получателя хранятся в серверных секретах. С пустым адресом открытка сохраняет предложение написать ответ вручную. Инструкции по настройке находятся в [README обработчика](backend/README.md).
